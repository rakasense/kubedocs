# kubedocs

Hands-on Kubernetes walkthroughs, published to GitHub Pages.

## Routes

| Module | URL |
|---|---|
| Deploying Workloads & the Controller Pattern | `/deploying-workloads-and-controllers/` |

## Development

Each module is a self-contained HTML file. Open it in a browser; no build step.

## Deployment

`.github/workflows/pages.yml` publishes the repo to GitHub Pages on every push to `main`. Configure Pages in the repo settings (`Settings → Pages → Source: GitHub Actions`) the first time.
